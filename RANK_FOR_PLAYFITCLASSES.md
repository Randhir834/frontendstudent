## ✅ SOLUTION: Do These 3 Things (30 Minutes Total)

### Step 1: Set Up Google Search Console (15 minutes)

This tells Google "Hey, I own playfitclasses.com!"

**Do this now**:

1. Open: https://search.google.com/search-console

2. Click: "Start Now" or "Add Property"

3. Type: `https://playfitclasses.com`

4. Click: "Continue"

5. Choose: "HTML tag" method

6. You'll see code like:
   ```html
   <meta name="google-site-verification" content="abc123xyz..." />
   ```

7. Copy only the code part: `abc123xyz...`

8. Open file: `/frontend/student/app/layout.tsx`

9. Find line 96:
   ```typescript
   google: 'your-google-verification-code', // TODO: Replace...
   ```

10. Change to:
    ```typescript
    google: 'abc123xyz...', // Use your actual code!
    ```

11. Save file

12. Deploy to production (push to GitHub/Render/Vercel)

13. Go back to Google Search Console

14. Click "Verify"

15. Should say "✅ Ownership verified"

---

### Step 2: Submit Sitemap (3 minutes)

1. In Google Search Console, click "Sitemaps" (left menu)

2. In the box, type: `sitemap.xml`

3. Click "Submit"

4. Wait for "✅ Success" message

**Done!** Google now knows all your pages.

---

### Step 3: Request Indexing (5 minutes)

1. At top of Google Search Console, find search box

2. Type: `https://playfitclasses.com`

3. Press Enter

4. Wait a moment

5. Click: "Request Indexing"

6. Click: "OK" or "Yes"

**Done!** Google will visit your site within 24 hours.
